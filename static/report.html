OCR Pipeline

Real-time Text Processing Pipeline — Project Report

Phase 1 — v2.0 (Task-based Viewer)

1. Project Overview

OCR 파이프라인은 텍스트를 실시간으로 수신·중복제거·저장·검색하는 시스템입니다.
Phase 1에서는 텍스트 Dedup, SQLite FTS5, 실시간 WebSocket 대시보드, Task 기반 문서 뷰어를 구현했습니다.

Phase 1 Scope

  • 완료 텍스트 중복 제거 (SequenceMatcher 85%)
  • 완료 SQLite + FTS5 전문검색 (Porter Stemmer)
  • 완료 WebSocket 실시간 대시보드
  • 완료 Task 기반 문서 그룹핑 + 캐러셀 뷰어
  • 완료 REST API (process, documents, search, tasks)

2. Architecture

LayerTechnologyDescription
API ServerFastAPI + UvicornREST + WebSocket endpoints
PipelinePythonDedup filter → Storage → Broadcast
StorageSQLite + FTS5문서 저장 + 전문검색 인덱스
FrontendVanilla JSDashboard + Task Viewer (SPA)
TransportWebSocket실시간 문서 도착 알림

Data Flow

Client POST /api/process (text, task_id) → DedupFilter (SequenceMatcher ≥ 85%) → MetaStore.save() (SQLite + FTS5 trigger) → WebSocket broadcast (new_document event) → Dashboard / Viewer 실시간 업데이트

3. Dashboard

실시간 대시보드 — WebSocket 연결 상태, 문서 수, 최근 문서 목록, FTS5 검색

Features

  • WebSocket 연결 상태 표시 (연결됨/끊김)
  • 실시간 문서 카운터 + 최근 문서 목록
  • FTS5 전문검색 (OR 연산, Porter Stemmer)
  • 상단 네비게이션 (Dashboard / Viewer / Conveyor)

4. Document Viewer (Task-based)

Task 기반 문서 뷰어 — 필터 칩 + Task 목록 사이드바

Task Grouping

  • 모든 문서는 task_id로 그룹핑
  • 상단 칩 필터로 Task별 빠른 전환
  • 각 Task는 문서 수, 생성/수정 시간 표시
  • 기존 문서는 default Task로 자동 분류

Carousel Navigation

  • 페이지 도트 인디케이터 (클릭 가능)
  • 위치 표시기: 1 / 3 형식
  • 키보드: ← → 문서 이동, j k Task 이동, / 검색

Paper 테마 적용 — meeting-notes Task

Card Rendering

5. API Reference

Example: Send with Task ID

curl -X POST http://localhost:8000/api/process \ -H "Content-Type: application/json" \ -d '{"text": "Chapter 1: ...", "task_id": "book-scan"}' # Response: {"status":"stored","doc_id":"doc_004","task_id":"book-scan", "title":"Chapter 1: ...","char_count":210}
