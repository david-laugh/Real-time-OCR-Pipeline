3 Dashboard

Real-time storage status, WebSocket connection, FTS5 text search in 3-column layout

Dashboard - Navigation bar + 3-column layout (Connection / Live Feed / Search)

Features

- Zone 1 (Connection): WebSocket status, QR module placeholder
- Zone 2 (Live Feed): Document counter, progress bar, real-time feed with slide-in animation
- Zone 3 (Search): FTS5 full-text search, results with source documents

Dashboard - 3 documents stored, LIVE WebSocket indicator
4 Document Viewer

Card-based document explorer with search, sort, theme switching, and keyboard navigation

Viewer - Document list (sidebar) + empty state with keyboard shortcuts
Viewer - Document detail (card rendering, metadata, navigation 1/3)
Dark theme
Paper theme
Viewer - FTS5 search result ("bread") with relevance score

Viewer Features

- Real-time search (300ms debounce, Enter for instant)
- Sort: newest / oldest / longest / shortest
- Theme: white card / dark / paper
- Font: Serif / Sans / Mono
- Keyboard: / search, j/k or arrows to navigate, Esc to close
- WebSocket: toast notification + auto-refresh on new documents
- Responsive: mobile layout support

5 API Endpoints

REST API + WebSocket for frontend communication

MethodEndpointDescription
POST/api/processText intake → dedup → store → WS broadcast
GET/api/documentsDocument list (with limit param)
GET/api/documents/{doc_id}Document detail (full content)
GET/api/statsStats (total docs, avg chars)
POST/api/searchFTS5 full-text search (OR query builder)
WS/ws/dashboardReal-time events (new_document, stats)
6 How to Run

No external API keys - runs fully local

pip install -r requirements.txt
python -X utf8 -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

# Pages
http://localhost:8000/         -- Dashboard
http://localhost:8000/viewer   -- Document Viewer
http://localhost:8000/conveyor -- Conveyor Test

# Send test data
curl -X POST http://localhost:8000/api/process \
  -H "Content-Type: application/json" \
  -d '{"text": "Your OCR-processed text here"}'
